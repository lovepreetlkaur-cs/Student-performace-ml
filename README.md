# Student Performance Prediction Using Machine Learning

## About the Project

This project explores whether student-related factors can be used to predict academic performance using Machine Learning.

The project uses student academic and behavioural data to identify patterns that may be related to student performance.

## Research Question

Can student-related factors be used to predict academic performance?

## Objectives

- Explore student academic data
- Clean and prepare the dataset
- Identify important factors related to performance
- Build Machine Learning models
- Compare model performance
- Analyse the results

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Status

This project is currently under development.
